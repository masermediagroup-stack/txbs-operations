# Triage labels

Canonical role -> label:

- needs-triage -> needs-triage
- needs-info -> needs-info
- ready-for-agent -> ready-for-agent
- ready-for-human -> ready-for-human
- wontfix -> wontfix

Before creating labels, inspect the repository's existing labels and preserve
equivalent established names. Apply triage to incoming raw reports, not tickets
already produced from an agreed specification.
